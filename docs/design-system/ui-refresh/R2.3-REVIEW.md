# R2.3 compact Header and sync presentation review

R2.3 implements the Header/sync unit of the Layered Clinical Workspace refresh.
Production changes are confined to `components/Header.tsx` and
`components/sync/SyncStatusBar.tsx`. Existing clinic switching, navigation,
permissions, sync providers, ownership, retries and clinical writes are retained.

## Reference and presentation

The live Claude artifact and its embedded claudeusercontent frame were inspected:
https://claude.ai/artifact/ESPAMmNxLt1caa2owyjSX5 . The frame confirms the clinic
above the role, a quiet sync surface, then Message delivery and account controls.
The matching checked-in `r0-pilot/index.html` supplies the visual authority.
R2.2 synthetic evidence remains available as the before baseline. No real-patient
or third-party reference directories were inspected.

The staff Header now presents clinic above role at every width. Each line truncates
independently, while the switcher's accessible name retains the full context.
The selected value is explicit: Radix otherwise copies the wrapping option content
into the trigger and expands the phone bar. The Header has a minimum height and
can grow with text. Pixel phone gutters preserve room for targets at 320px with
enlarged root text. A 6rem minimum for clinic context wraps the action group onto
a second row when necessary, preserving visible clinic/role text at 200%. Long clinic options wrap in the bounded existing Select.
Account destinations and the desktop collapse contract remain.

The sync target reserves 6.75rem below 600px (108px at default text, capped at 180px when enlarged) and
192px from 600px. Its inner surface
is at least 32px tall inside a target of at least 44px. Phones expose short state
labels and active-clinic counts, capped visually at 99+; accessible names retain
the complete state and other-clinic count. Full labels and the existing Sync now
control appear from 600px. An empty no-clinic state does not claim to be synced.

The existing seven-state priority and actions are unchanged. Persistent decorative
icon layers transition opacity, small scale and blur over the existing 150ms
strong ease-out. A reversal retargets the current transition. Text and accessible
names update immediately. Reduced motion removes icon motion and spinner rotation.
This is state indication at a small, occasional transition; no new motion library,
state timer, deferred status or queue logic was added.

## Validation

ESLint/Prettier, whitespace check and detector passed. ESLint retains its existing
repository-root Pages-directory configuration notice; it exits successfully.
Jest with at most two workers: **93 suites / 1019 tests passed**. Independent nav
unit expectations cover both station modes; no flag-off browser build is claimed.

Final-source focused coverage includes **64 distinct browser cases** plus six
authentication setups, verified across the 70-case run and Header/sync recheck.
The 70-case run reported **68 passed / 2 failed**: both isolated pill cases still
expected a literal `0s`, whereas the shared reduced-motion rule intentionally
clamps transitions to `0.01ms`. The corrected Header/sync file passed **6/6** with
no authentication setup rerun. The other 62 browser cases from the 70-case run
passed, including shell/role inventories, table state, More/sync focus handoff,
overlay motion, accessibility and actual sync conflict/offline recovery. This is
combined passing coverage, not a claim of a single 70/70 run.

The Header checks cover 320/390/599/600/744/767/768/1024/1199/1200/1440 in both
themes, long clinic and role text, a single-line clinic name, 44px targets, 200%
root text with visible clinic/role/status, no clinic, keyboard selection/account
access and clinic-switch success/refusal feedback. The phone bar may wrap its
actions for enlarged text. Screenshot review caught issues that target bounds
alone missed, and the assertions now retain visible context and status text.

The production pill fixture supplies synthetic queue/provider inputs and an
isolated pass-event subscription, without replacing production state priority,

both themes. Checks cover complete accessible names, final icon visibility,

no real outbox is mutated. Screenshots wait for finite transitions to settle and
