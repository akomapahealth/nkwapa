## Motion decisions

- Pointer dropdowns, submenus, Select and InfoHint: spatial continuity with their trigger, 200/160ms, scale 0.95 and opacity, existing ease-out token.
- Keyboard: immediate, including dismissal. Shared input tracking is needed because a browser check showed Radix can mark pointer-opened focus as focus-visible.
- Combobox: immediate. Focus, typing and selecting filtered suggestions are frequent and must not pay a motion cost. Its filtering, hidden state, active descendant and keyboard logic remain unchanged.
- Tooltips: 150/120ms, explicit 300ms skip-delay window, instant-open skips motion. Focus-opened tooltips are immediate.
- Reduced motion: fade only. A shared scoped exception preserves the fade despite the global 0.01ms clamp. No per-component media rules.
- Exit interruption: CSS transitions retarget; a nonvisual animation supplies the Radix Presence lifecycle event. No JavaScript timers or new dependency.

## Validation outcome

- Production build, standalone TypeScript, changed-file ESLint and Prettier passed.
- Jest: 92 suites, 1013 tests passed, max two workers.
- 58 distinct focused browser regressions passed, including all six new motion cases.
- Route harness: six roles, 228 rows, zero errors, zero serious/critical axe findings and zero horizontal overflow. 114 route screenshots.
- Open overlays: six scenarios at 390/744/1024 in light/dark completed all bounds and capture checks, producing 18 screenshots. These six test cases remain failed because their full-page axe assertions report the background aria-hidden-focus finding for both the menu and Select. Assertions were retained as soft assertions to capture every state; findings were not suppressed.
