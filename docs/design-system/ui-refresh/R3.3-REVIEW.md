shell collapse. Registry cards show actual names, patient codes, phone and ID
last-four fields; names explicitly use IBM Plex Sans and codes Plex Mono. Table
phone masking and existing routes remain. No pilot-only last visit, location
summary, queue state, age/sex or totals were fabricated.

Touch swipes call the same existing check-in operation as the explicit button.
A synchronous screen guard covers both entry points, including same-event
submissions. Post-gesture click suppression applies only to pointer clicks, so a
cancelled gesture cannot consume a later Enter/Space activation. Vertical-first movement, pointer cancellation, capture loss, resize,
blur, unmount and permission/busy changes cancel held gestures. Horizontal motion
tracks the pointer, resists beyond 112px and returns with a critically damped
spring; reduced motion returns immediately. The patient stays in the registry
after applied, queued and refused writes. Existing check-in feedback and replay
semantics remain. The pilot's simulated row removal and undo were not ported.
