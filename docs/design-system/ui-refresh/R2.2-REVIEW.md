# R2.2 phone BottomNav and More review

R2.2 extends the approved Layered Clinical Workspace shell below 600px. It adds
no routes, permissions, feature flags, API, database, clinical or sync behavior.
It preserves the 76px labelled tablet rail and 232/64px desktop sidebar.

## Reference fidelity

The live Claude artifact was opened and its embedded pilot inspected directly:
https://claude.ai/artifact/ESPAMmNxLt1caa2owyjSX5 . Its CSS agrees with the checked-in
`r0-pilot/index.html`: collapsed desktop labels are visually hidden at 1px and
available to assistive technology/tooltips; tablet labels are visible. A live
1440px collapse measured the artifact label at 1px with absolute positioning.
The production browser regression checks every collapsed sidebar link label,
then checks that tablet labels return. No Sidebar source change was necessary.
The proposed tablet concept was also inspected; it likewise shows visible labels.
No real-patient or third-party reference directories were inspected or included.

The production phone bar inherits the pilot's 60px row floor, icon-over-label
layout, 11.5px label role, teal current state and moving 2px top indicator. It uses
semantic tokens, a solid card surface and inset keyboard focus. The small brand
mark replaces the staff hamburger. The static artifact's Home/Stations/Assigned/
More sample is not a production permission model: R0-AUDIT section 5 and owner D7
require up to four authorized destinations in fixed priority, plus More, using
existing `app-nav.ts` labels. No sample metrics, illustrations or dashboard content
were copied into production. Dashboard content refresh remains R3.

## Shared contract

- `getMobileNavigation` partitions existing permission-filtered navigation. Up to
  four primary links follow Dashboard, Stations, Today Board, My Assigned, Queues,
  Patients, Appointments priority. Remaining sidebar destinations retain their
  groups in More; header/profile links and account/sync utilities remain reachable.
- Native disabled controls preserve clinic-dependent destinations without allowing
  `href="#"` navigation. Existing clinic-aware hrefs and nested active matching stay.
- More is a shared Radix bottom Sheet with title/description, a scrolling body and
  an 85dvh cap. No drag handle, new modal semantics or dependencies. R2.4 owns drag.
- Escape returns focus to More. Crossing 600px closes More and focuses main,
  avoiding focus on its now-hidden trigger. Navigation/history closes the sheet.
  Sync opens only after More releases its focus trap, using the existing provider.
  Its provider-controlled sheet now remembers the actual entry point and restores
  focus on close, with main as fallback when that control is gone or hidden. This
  fixes a confirmed keyboard return gap without changing the focus trap or queues.
- Chat clears the bar, and its panel height accounts for the additional space.
  Phone main clearance is 10rem plus safe area; other widths retain 6rem. The CSS
  variable defaults to zero outside the staff shell. No chat logic changed.
- Labels scale and wrap; horizontal and bottom safe areas are respected. The
  indicator uses a CSS transition and the existing global reduced-motion clamp.
  Portal navigation remains R2.5; wider header/sync presentation remains R2.3.
