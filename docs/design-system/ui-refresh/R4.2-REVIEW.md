# R4.2 review: Preceptor and manager oversight

**Scope:** frontend-only preceptor review and manager oversight on
`ui-refresh/r1-1-tokens`: the encounter's review step, the flag-off Today Board, Staff
activity, the manager dashboard section (`DirectorDashboard` staff table and
`StationFlowDashboard`), and the volunteer directory. Local commit only; no push. No
separate agent review ran.

Guidance applied: Impeccable (context loader, craft floor, detector), Emil design
engineering, Apple design. The only new motion is a 160ms disclosure chevron rotation
(removed under reduced motion).

## What the code says about roles

- **There is no preceptor role.** `ENCOUNTER.REVIEW` belongs to `DOCTOR` (and system
  administrators through `*`). The API sends the `review` dashboard block only beside the
  `doctor` block, so the "Review queue" tab label never shows alone. Preceptor coverage
  here means a doctor doing the review step.
- **Managers get the director section.** `DashboardService` maps `MANAGER` and `DIRECTOR`
  to the same `director` block ("Clinic trends"), plus Station flow when the station flag
  is on. Both roles hold `AUDIT.READ`, so linking that section to Staff activity is safe.
- **`/today` has two builds.** With the station flag on it is `StationLineBoard` (already
  ruled, unchanged here). With it off it is the assignment board, which CI's default e2e
  build runs. That board was the main redesign.

## What changed

- **Review leads.** A visit waiting on the reviewer opens with a "Ready for your review"
  band, in the place the sign-off band takes next: same shape, teal rule,
  `ClipboardCheck`, primary Mark Reviewed. Review locks nothing, so it does not use the
  warning ink kept for Finalize, Sign and Cosign. Mark Reviewed left the header, which
  now carries only Submit for Review. After the press, focus moves to the "Ready for your
  sign-off" heading that replaces the band.
- **Today Board (flag off).** Patient flow comes first, as one ruled list grouped by what
  the manager does next: Waiting for a pair, Assigned, In intake. Completed and Cancelled
  are closed `<details>` with counts. Before, it was five bordered kanban columns that
  scrolled sideways at 1440. Each check-in is a hairline `article`: name, code and arrival
  time, the pair as a `<dl>`, and actions right-aligned. Rows lay out by the list's own
  width (container query at 44rem). The shift control and Staff on duty sit in a 20rem
  column from 1200px. The role filter is a `SegmentedControl` whose labels carry the
  counts; it replaces pill buttons and three boxed count tiles plus a boxed Total and a
  boxed Queue Total. "Needs you now" shows only when someone is waiting and the viewer can
  assign, and the copy is pluralised correctly (it used to say "1 patients"). The no-clinic
  branch uses `SelectClinicState` instead of a bare paragraph. Headings are sentence case.
- **Staff activity.** Ranges and days use `formatOpsDate` and record times use
  `formatOpsDateTime`, replacing a raw ISO range and a local `Intl` formatter. The name
  column is sticky while the counts scroll sideways on a phone. Opening a person moves
  focus to their name; All staff returns focus to the row they left.
- **Manager dashboard.** The staff table says Name, Role (now "Volunteer", was
  `VOLUNTEER`), Visits started and Visits finalized, with right-aligned counts, and links
  to Staff activity. Station flow's past-day subtitle uses `formatOpsDate`. Its
  longest-wait note is a ruled warning band with an icon, not a tinted rounded box. Table
  rules use the rule token.
- **Volunteers.** Deactivate is a plain outline button, because Reactivate undoes it.

Unchanged: permissions, role and flag gates, transitions and their endpoints,
assignment and reassign validation, offline overlays and pending badges, every e2e hook
(`article` rows, the Assign button, "No patient check-ins yet", `ops-*` test ids,
`staff-activity-table`, `station-flow-*`), and the station-flag Today board.

  dashboard-work-first, volunteer-dashboard-refresh, workspace-smoke, clinical-notes,

## Ranked findings

- **P2:** No preceptor-only identity can exist, because review is a doctor permission.
  A separate preceptor role would be a product and auth change, not a design one.
- **P2:** The legacy Today group-heading font fix is unverified on screen (see above).
  Re-shoot it in the next flag-off build.
- **P3:** "Shift Status" (shared `ShiftControlCard`) still uses Title Case and its own
  heading size beside "Staff on duty". It is shared with Stations, so it is left for that
  owner.
- **P3:** On phones, Staff activity names wrap to two lines inside the sticky column.
  They are readable but the rows are tall.
- **P3:** Full-page phone screenshots catch the fixed bottom nav mid-page (capture
  artefact, not a layout bug).
- Carried forward: `portal-shell` held-changes baseline failure, open-overlay
  accessibility, transient sync, backend Crisis acknowledgement, Sunday appointment
  lifecycle, physical devices, Safari/Firefox, screen readers.
