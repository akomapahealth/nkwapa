IBM Plex Sans, mint/secondary/brand/status tokens, five contour swells and a wave

text, the greeting gets the full column and decorative art is omitted. Names
truncate independently while the accessible text remains complete. The same
controls and draft content stay mounted across width changes.

The dashboard reads shifts only with the station flag, active clinic and existing
`OPS.SHIFT.READ`. The read uses `fetchActiveShifts`; it does not request the station
board or acquire its permissions. `useOpsView` owns live/device copies under the
new `dashboard-shifts` cache kind, without an IndexedDB version change. Missing
first reads and refusals remain unknown, with retry. A refresh failure keeps
last-known data and displays the new additive `refreshError` result. Other
consumers are not changed to use that result.

Writes require `OPS.SHIFT.WRITE` and use `useShiftControls` / `useOpsWrite` /
`submitOpsWrite` unchanged in operation. Eligible roles keep the existing union
of effective and membership roles. A single role is stated; multiple roles use
the existing Select. The shared hook adds a synchronous in-flight guard and
rejects check-in when already on shift. A dashboard-only submission lock waits
for the existing read/overlay to reconcile, then releases; old feedback cannot
re-lock Start shift after a later server-side end. Pending starts/ends use
`usePendingOpsWrites` and `overlayPendingShifts`, with existing blocked/retry
recovery badges. New dashboard recovery buttons have 44px floors. No queue,
authentication, permission, clinical validation or backend implementation changed.

Needs you now remains above clinic totals and trends. Volunteer-only work rows
get numbered markers; their data, labels and permission-derived worklist links
remain. Personal intake counts stay once in the existing sentence. HAP totals,
draft/cosign breakdown, draft patient links, quick actions and all five charts
remain. Mixed-role dashboards retain their initial/persisted tabs and all other
role content; the new band sits inside the volunteer view. With the station flag
off, the shift component does not mount and existing dashboard content remains.
