# R4.1 review: Doctor review

**Scope:** frontend-only doctor-facing review on `ui-refresh/r1-1-tokens`: the HAP
note (draft, sign, cosign, addendum), encounter sign-off, the encounter's
prescriptions block, and the doctor/review dashboard sections. Local commit only;
no push. Queues were refreshed in R3.4 and are unchanged here. No separate agent
review ran.

Guidance applied: Impeccable (context loader, craft floor, detector), Emil design
engineering, Apple design. No new animation.

## What changed

- **Finalize asks once.** The sign-off band's Finalize opens the shared confirm
  dialog: "Finalize this visit?", "Every clinical tab becomes read-only and the
  visit leaves your sign-off queue." Focus starts on **Not yet**; the confirm is
  **Finalize visit** (teal, not destructive red). Before, one press finalized and
  locked the record. This is one added step, not a change to finalize semantics;
  three specs that finalize now confirm the dialog.
- **HAP note as a ruled section.** The card, the boxed care-team panel and the
  boxed read-only text are gone. Title and status; a provenance list (written by
  and role, care team at submission, submitted, signed or cosigned by whom); then
  History, Assessment and Plan as ruled blocks. Signed text reads as body text at
  a 70ch measure.
- **Cosign leads.** A note assigned to this doctor and pending opens with the
  encounter sign-off band, "Waiting for your cosign", holding the only Cosign
  note action. The dialog names the author ("You are signing for the note X
  wrote."). Previously a small outline button sat at the bottom of the note.
- **Draft actions** use `FormActions` split: save state at the start; Draft from
  the interviews, Save draft, then Sign note / Submit for cosign last. Add
  addendum is a right-aligned action row. Empty state is a ruled block, not a
  card, with the same two actions and a clearer sentence.
- **Addenda** and **prescriptions** are ruled lists. The Prescriptions panel and
  Add prescription form drop the card/box (only consumer: encounter page).
- **Times in Accra.** Note submitted/cosigned/addendum times, the encounter's
  Started time and the dashboard tables use `formatOpsDateTime` (Africa/Accra),
  replacing browser-locale `toLocaleString()`.
- **Dashboard.** Doctor and review tables share `recent-visit-columns.tsx`:
  Patient (link to the visit), Code, Status, Visit started. Section hints no
  longer claim these sections hold waiting work; they point to Needs you now.

Unchanged: permissions and role gates, cosign eligibility (doctor, assigned,
pending), note state machine, version checks, Ctrl/⌘+S, generator confirm,
offline note lockout, prescribing validation and allergy acknowledgement,
section titles and tab labels ("Doctor queue", "Review queue").

## Validation

- Audit-flag production build, standalone TypeScript, changed-file ESLint and
  Prettier pass. Detector over the changed UI files returns `[]`.
- Jest `--findRelatedTests` on the changed components finds no suites.
- Scratch screenshot spec (synthetic patient, mocked note states): **23/23**
  before and after, light and dark, 1440 and 390. Inspected: pending cosign,
  amended (signed + addendum), draft, cosign dialog, doctor dashboard.
  The first after-run found a real defect: naming the note wrapper "History,
  Assessment, and Plan" made `getByLabel('History')` ambiguous. Fixed by not
  naming that wrapper; the h2 still titles it.
- Focused Chromium, one worker, seven specs (clinical-notes, vitals, prescribing,
  diabetes-screening, workspace-smoke, volunteer-dashboard-refresh,
  dashboard-work-first): **50/50**, being 6 auth setups and 44 checks. Includes
  the new "a note awaiting this doctor leads with the cosign band" test and the
  three Finalize flows confirming through the new dialog.
- Six-role normal-route audit on the final build: **12/12, 228 rows, 0 axe
  violations, 0 horizontal overflow, 0 errors**.

Not run: full e2e, flag-off build, Safari/Firefox,
physical devices, screen readers. Finalize-cancel ("Not yet") has no e2e of its
own; the shared confirm dialog's cancel path is covered by its Jest test.

## Ranked findings

- **P2:** No seeded preceptor identity, so the review-only dashboard was seen only
  through a doctor holding both sections.
- **P2:** Screenshots of dialogs caught the open fade mid-way even with reduced
  motion; take dialog evidence after the transition ends.
- **P3:** Care team line repeats role words with synthetic names ("Volunteer
  Synthetic Volunteer"); reads naturally with real names.
- **P3:** On phones the draft's save-state note sits below the stacked actions
  (shared `FormActions` split behaviour from R3.8).
- Carried forward: `portal-shell` held-changes baseline failure, open-overlay
  accessibility, transient sync, backend Crisis acknowledgement, Sunday
  appointment lifecycle, physical devices.
