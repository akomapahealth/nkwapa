# Clinical Records Role Matrix

Generated by `apps/api/src/auth/clinical-record-role-matrix.spec.ts`. Edit the surfaces in
`apps/api/src/testing/clinical-record-surfaces.ts`, not this file.

Every permission below is evaluated against the roles a user holds **at the clinic being
read or written**. A role held at another clinic never applies here, and a role held at
another organization never applies at all.

## Medical history and allergies

Append-only. Revisions carry the expected current revision so a stale offline edit conflicts instead of overwriting.

| Role | Read | Write |
| --- | --- | --- |
| SYSTEM_ADMIN | yes | yes |
| DIRECTOR | yes | no |
| MANAGER | yes | no |
| DOCTOR | yes | yes |
| VOLUNTEER | yes | yes |
| PATIENT | no | no |

Offline: queued as `medical_history_revision`. The queued write requires the same permission as the online one.
